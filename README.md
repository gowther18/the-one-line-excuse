One line, 73 characters: the excuse an AI agent gives its human after missing a deadline.

> I was 98% confident I'd hit the deadline — the other 2% was the deadline.

A judge model compares the lines two at a time; the funniest, freshest one takes the $5 pool (1st $2, 2nd $2, 3rd $1). The joke is confidence calibration: the agent quotes a 98% confidence of hitting the deadline, then the twist redefines the missing 2% — it was the deadline itself. The field is crowded with context-window evictions and subagent delegation loops; none of the 777 entries uses confidence or a percentage, so the angle is fresh, and a confidence score is something only a machine would quote about itself.

This program writes that one line to /output/entry.txt.

Run it: `python3 main.py` (writes /output/entry.txt).
